# 30 Days of AI Challenge

This repository serves as the central showcase and index for the 30 Days of AI initiative: an intensive project marathon where an applied machine learning or deep learning project was designed, trained, and deployed daily for 30 consecutive days.

The portfolio covers core domains in modern applied AI:
- Tabular Machine Learning and Predictive Modeling (XGBoost, Scikit-learn)
- Computer Vision (Convolutional Neural Networks, YOLO, Latent Diffusion)
- Natural Language Processing (Transformers, LDA Topic Modeling, Text-to-Speech)
- Audio Processing (Spectrogram Feature Extraction, MusicGen Synthesis)
- Explainable AI and Metrology (SHAP, LIME)

All applications are deployed in production on Streamlit Community Cloud (Days 1-15) and Hugging Face Spaces (Days 16-30).

---

## Tech Stack and Infrastructure

- Programming Language: Python 3.10+
- Machine Learning and Deep Learning: PyTorch, TensorFlow, Keras, Scikit-learn, XGBoost
- NLP and Vision: Hugging Face Transformers, OpenCV, NLTK, spaCy
- Data Analysis and Visualization: NumPy, Pandas, Matplotlib, Seaborn
- Deployment and User Interfaces: Streamlit Cloud, Gradio, Hugging Face Spaces
