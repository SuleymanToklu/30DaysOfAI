# 🚀 30 Days of AI Challenge 🚀

Hello! This repository is a log of my **"30 Days of AI"** journey, a personal challenge where I developed a new artificial intelligence project every single day for 30 days.

As a Computer Engineering student at Isparta University of Applied Sciences, I aimed to put my theoretical knowledge in AI into practice, enhance my skills, and get one step closer to my goal of becoming an AI Engineer. This journey helped me improve my problem-solving abilities, project management discipline, and my command of various AI technologies.

## 🌟 About This Repository

This repository contains the source code, descriptions, and live demo links for all the projects I developed during my `30DaysOfAI` challenge. The projects span various subfields, including Machine Learning, Deep Learning, Natural Language Processing (NLP), and Computer Vision.

## 🛠️ Tech Stack & Tools

Throughout this 30-day period, I primarily used the following technologies:

* **Programming Language:** Python
* **Libraries & Frameworks:**
    * TensorFlow & Keras
    * PyTorch
    * Scikit-learn
    * Pandas & NumPy
    * Matplotlib & Seaborn
    * OpenCV
    * Hugging Face (Transformers, Datasets)
    * NLTK & spaCy
* **Tools:** Jupyter Notebook, Google Colab, Git & GitHub, VS Code
* **Deployment:** Streamlit Cloud, Gradio, Hugging Face Spaces, Heroku
